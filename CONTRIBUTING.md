# Contributing to code2paper

Thank you for your interest in contributing to `code2paper`!

## Guidelines
1. **Skill-first**: The product is `skills/code2paper.md` — a self-contained agent skill.
   Keep it usable in any AI agent without external dependencies.
2. **Honesty**: The skill must produce code-grounded output. No invented metrics,
   no unverified claims, no boilerplate.
3. **Language coverage**: Import syntax and entrypoint tables must stay current with
   the 2026 ecosystem (100+ languages).

## Workflow
1. Fork and clone the repository.
2. Create your feature branch (`git checkout -b feature/amazing-skill`).
3. Improve `skills/code2paper.md` and test it inside your AI agent on a real repo.
4. Commit your changes following conventional commits (`feat: add Rust pattern coverage`).
5. Push to the branch and submit a Pull Request.
