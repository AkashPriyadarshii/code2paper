# Design & Style Specification: code2paper

## Output Format
- **Default Engine**: Typst (`paper.typ` -> `paper.pdf`).
- **Secondary Engine**: LaTeX (`paper.tex`).

## Paper Layout Specification
- IEEE two-column paper format.
- Sections:
  1. Abstract & Keywords
  2. Introduction & Problem Definition
  3. System Architecture & Component Design
  4. Core Algorithms & Mathematical Formalization
  5. Implementation & Module Details
  6. Limitations & Future Work
