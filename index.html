⚡

Zero-Dependency Core

Runs purely on Python standard library modules (`os`, `sys`, `subprocess`, `argparse`). No heavy package installs needed.

🌐

Zero-CLI WebPaper HTML

Auto-generates standalone MathJax-powered HTML papers. Print directly to PDF from any web browser without needing local CLI compilation tools.

🤖

Claude Agent Skill

Includes native `/code2paper` agent skill definition with automatic prompt level checks, mathematical formalization passes, and diagram generation.

Get Started in Seconds

Clone the repository and run the CLI directly.

git clone https://github.com/AkashPriyadarshii/code2paper.git && cd code2paper && python code2paper.py .
